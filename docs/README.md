# 文档说明

用户手册与知识库统一维护在 [Mi-Bee-Studio/mibee-docs](https://github.com/Mi-Bee-Studio/mibee-docs) 的 `mibeecam/` 目录（[官网 https://www.mlsbs.top/docs/mibeecam](https://www.mlsbs.top/docs/mibeecam)，中英双语；部署指南见其中的 rpicam-deployment / rpicam-rs 页）。面向用户的文档页面请提交到 mibee-docs（slug 前缀 `rpicam-`），不要新增在本仓库。

本目录保留**未收录**的工程文档：

- `features/ai-detection.md` — AI 检测（**已实现**）：选型、预处理/后处理、推理管线
- `features/multi-camera.md` — 多摄像头（规划中）：并发模型与技术选型
- `features/webrtc.md` — WebRTC（规划中）：信令/ICE/DTLS/SRTP 路线对比
- `features/h265.md` — H.265 编码（规划中）：硬件 M2M 与软件回退路线
- `nvr-integration-notes.md` — NVR 互操作与流媒体排障工程笔记
